# 🚀 Featured Project

## AI Interview Platform

### 🔗 Live Demo

https://ai-interview-platform-full-project.vercel.app/

https://github.com/nikhil1-ux/Ai-interview-platform-full-project

---

### Overview

An AI-powered recruitment platform where recruiters create interviews from Job Descriptions, candidates upload resumes, AI generates personalized interview questions, candidates complete live interviews, and recruiters receive automated evaluation reports.

---

## Features

### 👨‍💼 Recruiter

- Secure Authentication
- Recruiter Dashboard
- Create Interview
- Assign Candidate
- Resume Upload
- Interview Analytics
- Candidate Ranking
- AI Evaluation Reports

### 👨‍🎓 Candidate

- Secure Login
- Candidate Dashboard
- Assigned Interviews
- Resume Upload
- AI Generated Questions
- Real-Time Interview
- Automatic Evaluation
- Performance Report
